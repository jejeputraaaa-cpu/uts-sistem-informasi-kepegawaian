# Sistem Informasi Kepegawaian

Aplikasi web Sistem Informasi Kepegawaian dibangun menggunakan Laravel dan MySQL untuk mengelola data departemen dan pegawai.

## Fitur

-Authentication: login dan logout.
-CRUD departemen.
-CRUD pegawai.
-Relasi departemen dan pegawai.
-Validasi data.
-Database migration dan seeder.

## Teknologi

-Laravel
-PHP
-MySQL
-Blade
-Git dan GitHub

## Instalasi

1.Clone repository ini.
2.Jalankan `composer install`.
3.Salin `.env.example` menjadi `.env`.
4.Atur koneksi database pada file `.env`.
5.Jalankan `php artisan key:generate`.
6.Jalankan `php artisan migrate --seed`.
7.Jalankan `php artisan serve`.
